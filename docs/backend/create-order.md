# Создание заказа

## Метод

`POST /orders`

## Атрибуты запроса

| Атрибут | Тип     | Обязательный | Описание                  |
|---------|---------|--------------|-----------------------------|
| user_id | integer | да           | ID пользователя             |
| items   | array   | да           | Список товаров в заказе (от 1 до 50 позиций) |
| items[].product_id | integer | да | ID товара              |
| items[].quantity   | integer | да | Количество товара, больше 0 |
| delivery_address   | string  | да | Адрес доставки         |
| promo_code         | string  | нет | Промокод на скидку    |
| comment            | string  | нет | Комментарий к заказу, до 500 символов |

## Алгоритм работы

1. Проверить, что все `product_id` из запроса существуют.
2. Проверить наличие нужного количества товара на складе.
3. Рассчитать `total_amount` как сумму `price * quantity` по всем позициям.
4. Если передан `promo_code`, проверить, что он активен, и применить скидку к `total_amount`.
5. Зарезервировать товар на складе.
6. Создать запись в `orders` со статусом `created`.
7. Создать связанные записи в `order_items`.

## Пример запроса

```json
{
  "user_id": 42,
  "items": [
    { "product_id": 101, "quantity": 2 },
    { "product_id": 205, "quantity": 1 }
  ],
  "delivery_address": "г. Москва, ул. Тверская, д. 1, кв. 10",
  "promo_code": "AUTUMN10"
}
```

## Пример ответа

```json
{
  "id": 987,
  "status": "created",
  "total_amount": 3105.00,
  "discount_amount": 345.00
}
```

## Коды ответа

| Код | Когда возвращается                                  |
|-----|-------------------------------------------------------|
| 201 | Заказ успешно создан                                   |
| 400 | Невалидное тело запроса (пустой items, отрицательное quantity) |
| 404 | Один из product_id не найден                           |
| 409 | Товара недостаточно на складе                          |
| 422 | Промокод не найден или истёк                           |
